# Conta Bancária

## Sobre o projeto:
### Este projeto é um pequeno sistema backend simulando uma conta bancária. Na aplicação o usuário pode inserir seu nome, o tipo de conta e realizar operações bancárias de depósito e saque, além de verificar a conta.
### Caso o valor de saldo da conta bancária esteja negativado, o sistema informa que o usuário está utilizando o cheque especial.

### O objetivo deste projeto foi a prática de Java sendo este meu primeiro projeto utilizando a linguagem. Os conceitos trabalhados foram a criação de variável, input de informações pelo usuário e estruturas condicionais.

# Bank Account

## About the project:
### This project is a simple backend system that simulates a bank account. In the application, users can enter their name and account type, perform bank operations such as deposits and withdrawals, and check their account information.
### If the bank account balance is negative, the system will notify the user that they can use the overdraft.

### The objective of this project was to practice Java, and this is my first application using this language. The concepts used were variable creation, input informations by user and conditional structures.
